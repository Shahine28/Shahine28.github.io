## Context

This game marks my debut in mobile development, created during a month-long team project focused on brainstorming. The fruit of the skills acquired during the first semester of my second year at IIM, it bears witness to the collaboration of each team member in their own field to create this mobile game.

## Team

- 3 Game Programmers
- 2 Game Designers
- 3 Game Artists

## Tasks

- Integration of ingredient cards
- User interface integration
- Immersion enhancement (particles, camera vibrations, sound effects, etc.)
- Implementation of touch controls
- Programming of monster behavior
- Development of the dish system
