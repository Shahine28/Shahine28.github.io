## Context

This project was carried out in collaboration with Inktober 2023, where I took on the challenge of coding every day for a month. It was a thrilling adventure in which each day brought its own new ideas and developments, in the stimulating setting of this iconic artistic challenge.

## Tasks

- AI with A* pathfinding
- Advanced inventory system
- Crafting system
- Shop system
- Chest system
