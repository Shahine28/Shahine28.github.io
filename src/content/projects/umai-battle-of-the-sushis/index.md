## Context

This project represents the culmination of three years of intensive learning at the IIM as part of my Bachelor's in Video Game Development. Developed in just two months on Unreal Engine 5 using C++, UMAI! is the result of a dynamic and creative collaboration between various fields of expertise. It showcases not only my technical skills but also my ability to thrive in a team-oriented production environment.

## Team

- 2 Game Programmers
- 2 Game Designers
- 3 Game Artists
- 3 Producers
- 1 Sound Designer

## Tasks

- Local Multiplayer: Full system implementation, intuitive player selection menu.
- Boat System: Projectile handling, dynamic health bar, sinking animations.
- Core Gameplay: State Machine, Craft Manager, Item Spawn Manager, Animation Manager.
- Interactive Objects: Pickup items, crafting tables, modular projectiles with effects.
- Advanced Mechanics: Dynamic buoyancy using Unreal Engine's Water plugin.
