# Shahine Benthanane - Portfolio

Source of [shahine28.github.io](https://shahine28.github.io), built with [Astro](https://astro.build) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Run locally

```sh
npm install
npm run dev
```

## Add a project

Each project is a folder in `src/content/projects/<slug>/` with an `index.md` (fields described in `src/content.config.ts`), a `cover` image and a `media/` folder. The full procedure is in `.claude/skills/add-project/SKILL.md`.
